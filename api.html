API

The GuideCensus API

The frozen census is queryable over a public, read-only REST API.

Base URL: https://api.guide.erbihou.org/v1

All endpoints are GET and return JSON.

Endpoints marked v2 activate with the v2 worker deployment.

Endpoints

GET /v1/health

Liveness check.

https://api.guide.erbihou.org/v1/health

GET /v1/stats

Row counts of the four database tables.
